# Newtake(뉴테이크) 영상 제작 방법 정리

사용자가 보내 준 유튜브 강의 2편(2026-11-12 시청)에서 정리한 작업 방법. 쿠팡 숏츠에 사람이 쓰는 장면을 넣기로 하면 이 순서대로 한다.
- 영상 1: "노드 방식의 끝판왕 AI 영상제작 플랫폼, Newtake AI" (KyuQ캡틴규큐) https://www.youtube.com/watch?v=GpweFsFTd0Q
- 영상 2: "1인 영상 제작자를 위한 AI 스토리보드 자동화" (갓찌뇽의 초보여도 괜찮아) https://www.youtube.com/watch?v=QFwz__deXUs
- 접속: https://www.newtake.com (로그인은 사용자가 직접)

## 기본 구조
- 프로젝트 하나 = 캔버스 하나. 이미지·영상·오디오가 모두 노드이고, 노드를 선으로 이으면 앞 결과가 다음 생성의 재료가 된다.
- 생성 전에 항상 크레딧 소모량을 확인하는 단계가 있다. 누른다고 바로 결제되지 않는다.
- 이미지 모델(GPT 이미지 2 = 품질 좋고 비쌈, 나노 바나나 2 = 저렴), 영상 모델(시댄스 2.5 = 자연스러움, 완 3.0 = 스토리보드에 충실하고 크레딧 적게 듦)을 노드마다 고른다.
- 홈의 "디렉터 도구"에 기능별 샘플 프로젝트가 있어 노드 구성을 그대로 참고할 수 있다.

## 핵심 기능 5가지
1. **멀티 앵글 생성**: 사진 1장 → "멀티카메라 9 그리드"로 같은 인물·배경의 9개 각도. 마음에 드는 칸만 골라 "고화질 이미지 생성"으로 따로 뽑는다. 다각도 편집기 프리셋: 어안, 기울인 시점, 정면 부감, 정면 앙각, 파노라마 부감, 후면. 수동으로 수평 회전·수직 위치·샷 크기 조절.
2. **스토리보드**: 사진 1장 + 줄거리 프롬프트 → "스토리 전개 4 그리드"(짧게), "9 그리드"(티저용), "25 그리드 연속 스토리보드"(자세하게, 크레딧 많이 듦). 필요 없는 컷은 빼고 나머지를 비디오 노드에 연결.
3. **구간 리메이크**: 만들어진 영상의 타임라인에서 고칠 구간만 지정하고 프롬프트로 그 부분만 다시 생성. 전체를 다시 만들지 않는다.
4. **영화급 조명 보정**: 이미지 조명을 바꾼다. 빛의 양·각도 조절, 샘플에서 고르는 스마트 모드.
5. **스마트 영상 분석**: 참고 영상을 올리면 컷·모션·음악으로 쪼개 준다. 원하는 컷을 비디오 노드에 연결하고 프롬프트를 주면 그 구성을 따라 새 영상을 만든다.

보조 기능: 캐릭터 디자인 시트(얼굴 3면도 / 설정도 / 전신 3면도 — 일관성에는 전신 3면도), 인물 질감 조정(AI 티 나는 매끈한 피부를 사실적으로), 감정 조정(25단계), 파노라마(세로 사진을 가로로), 업스케일.

## 제품 광고 만드는 순서 (영상 2의 텀블러 광고)
1. 새 프로젝트를 만들고 **실제 제품 사진**을 올린다. 광고는 제품이 바뀌면 안 되므로 생성 이미지가 아니라 실제 사진에서 출발.
2. 멀티카메라 9 그리드를 누르되 AI에게 맡기지 말고 프롬프트를 직접 쓴다. 프롬프트에 넣을 3가지:
   - 컷마다 **시간과 장소** (예: 새벽 5시 스튜디오 앞 → 대기실 거울 → … → 밤 9시 불 꺼진 스튜디오)
   - **바뀌어도 되는 것** (예: 모델 의상은 컷마다 달라도 됨)
   - **절대 바뀌면 안 되는 것** (제품 모양, 인물 얼굴)
3. 9컷을 비디오 노드에 연결, 시댄스 2.5, 8초 안팎으로 생성. 더 길고 자세하게는 25 그리드 → 원치 않는 컷 제외 → 15초.
4. 어색한 구간은 구간 리메이크로 그 부분만 수정, 스마트 편집으로 마무리.

기획 요령: 제품을 직접 자랑하지 않고 이야기 속 소품으로 둔다(하루 종일 옷은 바뀌는데 텀블러만 그대로). 컷마다 조명 색이 시간대에 맞게 달라지면 영상이 살아난다.

## 쿠팡 숏츠에 적용할 때
- 제품 사진 = 쿠팡 상세페이지의 깨끗한 제품 컷(coupang/details).
- 프롬프트의 "바뀌면 안 되는 것"에 제품 모양·색·로고를 명시. 결과 컷에서 제품이 달라졌으면 버린다.
- 9:16 세로, 5~8초 클립 1~2개를 도입부에 넣고 나머지는 기존 생성기(make_product_short.py, style=panda)로 만든다.
- 써 보지 않은 상품이므로 "써 보니 좋다"는 대사·자막은 넣지 않는다. 광고 표시 문구 유지.
- 캔버스 조작은 브라우저에서 수동으로 해야 하므로 하루 1~3개 고퀄 영상용. API 유무와 요금은 아직 확인 안 됨.
